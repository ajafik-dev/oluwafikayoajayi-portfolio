Selected products

Church apps, visitor management, and operational suites.

What each product does. Most of these share a stack: a Go API, a Next.js portal, and an Ionic app.

Mobile · Web · API

MFM Zion

Member app, admin dashboard, and public church site for MFM Zion Assembly. Members, groups, ministries, events, sermons, attendance, offerings, community feed, reminders, and a hymnal, scoped to the active church, with a command centre for platform operators.

Ionic mobile, Next.js admin, Go API. Public site at mfmzionassembly.org.ng.

Mobile · Web · API

MFM Evangelism

Field and admin tools for MFM evangelism staff: decision-slip capture, call-centre workflow, 72-hour visit follow-up, escalations, and offline sync.

Ionic mobile, Next.js admin, NestJS API.

Web · Mobile · API

Bookme4Visit

Multi-tenant visitor management with QR tickets, check-in and check-out, role-based access, and realtime updates. One login on web and mobile. The UI adapts for admins, hosts, security, and visitors.

Next.js portal, Ionic app, Go API.

Web · Mobile · API

SchoolCore

Multi-tenant school management: parent reporting, fees, messaging, timetable, admissions, transcripts, and role-specific shells for admin, teacher, parent, student, and accountant.

Next.js, Ionic, Go API. Part of the Core Apps suite.

Web · Mobile · API

FuelCore

Gas-station operations: stations, tanks and pumps, shifts, wetstock, POS, prices, fleet, and alerts. HQ admin and station portals on the web; field roles on mobile.

Next.js, Ionic, Go API. Part of the Core Apps suite.

Web · Mobile · API

StockCore

Inventory and purchasing: HQ catalog and procurement, store receiving and transfers, barcode scan, counts, and write-offs with proof.

Next.js, Ionic, Go API. Live web at stockcoreweb.netlify.app.

Web · Mobile · API

CoopCore

Cooperative society suite: members, contributions, loans, dividends, store, ledger, USSD, and field-agent collect. Staff use the web; members and field agents use mobile.

Next.js, Ionic, Go API. Part of the Core Apps suite.

Web · Mobile · API

PayCore

Multi-tenant payroll and HR: admin web plus employee self-service on web and Android.

Next.js, Ionic, Go API. Part of the Core Apps suite.
